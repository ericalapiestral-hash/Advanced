# 두 사람의 작은 가게 (가제)

한 사람에게 선물하기 위해 Unity로 만드는 2D 도트 방치형 가게 게임.
재료를 모으고, 상품을 만들어 팔고, 강화하고, 도감을 채우며 가게를 키운다.
가게가 자랄 때마다 두 사람의 추억이 열리고, 엔딩에는 편지가 기다린다.

- 플랫폼: Windows PC, 싱글플레이, 오프라인
- 엔진: Unity 6.3 LTS, Universal 2D (URP), uGUI + TextMeshPro

- 게임 설계: [docs/DESIGN.md](docs/DESIGN.md)
- 아이디어 보관함: [docs/IDEAS.md](docs/IDEAS.md)
